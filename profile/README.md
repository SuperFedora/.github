# SuperFedora

**Curated 16-bit native Rust workstation on clean Fedora.**  
*Hyprland / COSMIC Keybindings / SuperShell / SuperForge / SuperTheme / SuperAgent / Snapper Rollbacks*

**[Official 16-Bit Portal & Documentation: superfedora.github.io](https://superfedora.github.io/)**

```bash
curl -fsSL https://superfedora.github.io/install.sh | bash
```

### Organization Repositories

* [**superfedora**](https://github.com/SuperFedora/superfedora) — Core orchestrator CLI/TUI (`superfedora` / `sf` alias), `systemd` session & OS tuning, modular installers (`00..90`), and dotfiles.
* [**superforge**](https://github.com/SuperFedora/superforge) — Native Rust `-march=native` / LTO source builder (`superforge`), recipe catalog, and chromeless Firefox WebApp engine.
* [**supertheme**](https://github.com/SuperFedora/supertheme) — Native Rust 16-bit theme & SFX controller (`supertheme`), 16 rainbow palettes, wallpapers, 10 animated cast portraits, and WAV synth.
* [**supershell**](https://github.com/SuperFedora/supershell) — Native Rust 16-bit desktop shell workspace (`superdock`, `superbar`, `supersettings`, `superlock`).
* [**supernotify**](https://github.com/SuperFedora/supernotify) — Standalone 16-bit animated Cast Comms (10 specialists), arcade stage banners (`READY`, `WARNING`, `UPDATE`, `CHECKPOINT`), and notification center (`supernotify`).
* [**superagent**](https://github.com/SuperFedora/superagent) — Autonomous workstation AI daemon & CLI (`superagent`) for OpenClaw, Ollama, coding agents, and Cast Comms relays.
* [**superfedora.github.io**](https://github.com/SuperFedora/superfedora.github.io) — Public 16-bit web portal, architecture documentation, and bootstrap CDN.
* [**.github**](https://github.com/SuperFedora/.github) — Organization profile, reusable CI workflows, and canonical `AGENTS.md` house laws.
